Data Analytics

Olist WBR Command Center

Weekly review of delivery performance and review scores for about 96K delivered orders.

Problem
Build a weekly business review for an e-commerce business using the Olist dataset (~96K delivered orders).
Approach
Shared metric definitions across PostgreSQL, Python, Excel and Power BI. Built a read-only SQL agent in Python (Groq/Gemini LLM) that drafts SELECT-only queries, validates them with sqlparse, runs them under a read-only database role with query logging, and checks generated commentary against computed figures.
Result
Late deliveries averaged a 2.27 review score vs 4.29 on time (62% vs 9% low-star share).

Full-Stack Web App

AquaShield Waterproofing Platform

Customer, partner, and admin workflows for a waterproofing company, on one backend.

Problem
A waterproofing company needed enquiry-to-warranty workflows and a partner referral program in one system.
Approach
Customer/partner site and admin panel on one Supabase backend. Security enforced with PostgreSQL Row Level Security, private storage with signed URLs, and SQL triggers for payment checks, GST totals and commissions. Built with AI-assisted development: I owned requirements, architecture and review; an AI assistant generated code and ran SQL tests on local PostgreSQL.
Result
Deployed on Vercel with demo data. Not yet tested with real users.
